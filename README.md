# CareerTrail

CareerTrail is a production-style .NET backend platform for managing job applications, interviews, resumes, notes, and follow-ups.

## 📌 Overview

CareerTrail helps job seekers organize their job-search workflow in one place. It will allow users to track applications, manage resume versions, record interviews, add notes, schedule follow-ups, and view application insights.

## 🎯 Goals

- Build a clean, maintainable ASP.NET Core Web API
- Apply Clean Architecture principles
- Design a relational database using Entity Framework Core
- Implement secure authentication and authorization
- Write meaningful unit and integration tests
- Use Git feature branches and a clear commit history
- Document architecture and engineering decisions

## 🧱 Planned Architecture

The solution follows Clean Architecture:

- **CareerTrail.Domain:** Core entities, value objects, and business rules
- **CareerTrail.Application:** Use cases, application services, and interfaces
- **CareerTrail.Infrastructure:** EF Core, SQL Server, and external services
- **CareerTrail.Api:** ASP.NET Core REST endpoints

## 🛠️ Technology Stack

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- xUnit
- Git and GitHub
